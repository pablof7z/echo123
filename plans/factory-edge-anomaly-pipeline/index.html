Factory Edge Anomaly Pipeline

Add an edge pipeline for factory sensor anomalies. Gateways compute feature windows near machines, buffer during outages, and publish normalized anomaly candidates to central ingestion. The server persists telemetry and routes severe anomalies to analyst review.

Existing Rules Or ADRs

  • Satisfies ADR 0001 through clear gateway, ingest, storage, alerting, and review boundaries.
  • Satisfies ADR 0002 if stream and model vendors remain adapters.
  • Satisfies ADR 0003 by using existing alert audit paths.

Rule Tension And Tightening

  • Low risk. Vendor coupling is the main concern; normalized messages and adapters avoid it.
  • No rule needs loosening.
  • Add an edge workflow rule covering stale config, local retention, drop accounting, and remote disable controls.

Alternatives Considered

  • Cloud raw telemetry: simple, expensive, outage-sensitive.
  • Full edge models: low latency, high deployment burden.
  • Daily batch summaries: cheap, misses urgent anomalies.
  • Vendor-managed monitoring: fast, less portable.

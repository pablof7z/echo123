Field Clinic Intake Sync

Add an offline-first intake lane for field clinic teams. Mobile clients write signed intake packets into an encrypted local outbox, a sync adapter retries delivery, and the server validates, deduplicates, and stages packets for clinical review before patient-record promotion.

Ready to implement 88 percent certainty Bounded surface

Boundaries

flowchart LR
  Mobile[Mobile intake] --> Outbox[Encrypted outbox]
  Outbox --> API[Sync API]
  API --> Review[Review queue]
  Review --> Record[Patient record]
  API --> Audit[Audit log]

Existing Rules Or ADRs

  • Satisfies ADR 0001: boundaries are explicit.
  • Satisfies ADR 0002: core workflow is portable.
  • Satisfies ADR 0003: receipt, review, promotion, duplicate handling, and rejection are auditable.

Rule Tension And Tightening

  • Low violation risk. Temporary staging storage is not a new source of truth.
  • No rule needs loosening.
  • Consider requiring offline workflows to define idempotency, conflict policy, and reconciliation owner.

Alternatives Considered

  • Direct mobile write to patient record: simpler, weaker conflict control.
  • General offline framework: broader dependency surface.
  • CSV export/import: familiar, poor audit and latency.

# echo123

Example repository for architectural planning PRs.

This repository is intentionally small. Its pull requests demonstrate a proposed Codex skill workflow where complex assigned work first opens a planning PR with:

- a concise PR-body plan,
- a detailed documentation file,
- generated TTS narration,
- rule and ADR checks,
- alternative designs,
- certainty scoring,
- and an explicit proceed-or-pause decision.
